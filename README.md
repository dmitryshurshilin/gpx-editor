# GPX Editor

Редактор GPX-треков на React. Файлы обрабатываются на устройстве; сервер для загрузки, коррекции и экспорта не нужен.

## Разработка

Требуется Node.js 20.19+ или 22.12+. Версия для nvm указана в `.nvmrc`.

```sh
nvm use
npm ci
npm run dev
```

Откройте адрес, указанный Vite. Для сборки и проверки:

```sh
npm test
npm run build
npm run format:check
npm run preview
```

Публикуется содержимое `dist/` на любом статическом HTTP-хостинге. Сборка поддерживает размещение в подкаталоге. Открытие исходного HTML через `file://` не поддерживается. React и Leaflet включаются в сборку; подключение нужно для подложек карты.

## Структура

```text
public/                         # Статические файлы, логотип
src/
  app/                          # Сборка приложения, шапка, справка
  domain/gpx/                   # GPX-модель, геометрия, автокоррекция
  features/
    editor/
      components/               # Загрузка, инструменты, GPX-код
      model/                    # EditorStore и React Context
    map/
      components/               # Карта и её элементы управления
      hooks/                    # Жизненный цикл карты в React
      services/                 # Leaflet, Canvas, жесты и экспорт PNG
  shared/lib/                   # Форматирование и скачивание файлов
  styles/                       # Общие стили и адаптивная вёрстка
tests/                         # Тесты модели, состояния и карты
```

`TrackModel` сохраняет XML и историю изменений. Модель не зависит от React или Leaflet. `EditorStore` управляет действиями пользователя и публикует кешированные снимки состояния через `useSyncExternalStore`. Компоненты получают состояние из Context и отправляют действия в хранилище.

Карта создаётся в `useEditorMap` и полностью очищается при размонтировании, включая обработчики, наблюдатель размера и отложенные кадры. Leaflet управляет только своим контейнером; React управляет кнопками и панелями. Точки рисуются на Canvas с пространственным индексом. При перетаскивании обновляются только соседние отрезки; XML и React-состояние обновляются после завершения жеста.

Новые операции над GPX добавляйте в `domain/gpx`, пользовательские действия — в `EditorStore`, новые панели — в соответствующую папку `features`. Не добавляйте глобальные пространства имён и прямое изменение DOM React-компонентов.

## Возможности

- Загрузка GPX до 20 МБ и демонстрационный трек.
- Добавление точки кликом по линии, перемещение, удаление двойным кликом.
- Выделение рамкой, сброс и удаление фрагмента; соединение соседей внутри исходного сегмента.
- Предпросмотр автокоррекции: вылеты между скачками больше выбранного порога (по умолчанию 500 м) подсвечиваются оранжевым, будущие соединения — зелёным пунктиром. Удаление выполняется только после подтверждения. Возврат подтверждается следующим интервалом меньше порога; незавершённые вылеты сохраняются.
- Порог автокоррекции задаётся целым положительным числом метров. Изменение порога сбрасывает предпросмотр; нужно запустить его повторно.
- Отмена добавления, перемещения, удаления и автокоррекции.
- Полноэкранное редактирование без удаления; выход кнопкой или Esc.
- Подложки OpenStreetMap и Esri World Imagery.
- Скриншот выбранной области с атрибуцией, имя `map-screen_yyyymmdd-hhmmss.png` по местному времени.
- Просмотр, копирование и скачивание GPX с сохранением метаданных и времени существующих точек.

Для PNG используются доступные браузеру тайлы с CORS. Пока тайлы не загрузились, экспорт предложит повторить попытку. Скриншот не отправляется на сервер.

## Версии и обновления

Версия приложения и дата обновления показываются в футере. Их единственный источник — `version` и `releaseDate` в `package.json`; дата хранится как `YYYY-MM-DD` и отображается как `ДД.ММ.ГГГГ`. Повторная сборка не меняет дату выпуска.

Каждая доработка получает новую версию SemVer: новая совместимая возможность повышает minor, исправление или визуальная доработка — patch, несовместимое изменение — major. Версия синхронизируется с `package-lock.json`. Если задача задана нумерованным списком, каждый пункт оформляется отдельным коммитом с собственной версией. После изменения кода пересобирайте `dist/` командой `npm run build`.
