# gpx-editor
GPX Editor

## Локальный запуск

Откройте `index.html` в браузере. Приложению не нужны сборка и бэкенд; для карт нужен интернет.

Скриншоты карты сохраняются как `map-screen_yyyymmdd-hhmmss.png`, по местным дате и времени устройства.

## Проверки

Тесты скриншотов используют встроенный тестовый модуль Node.js без дополнительных зависимостей:

```sh
node --test tests/map-screenshot.test.cjs
```
